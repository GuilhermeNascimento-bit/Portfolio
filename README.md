# Portfolio

My personal portfolio site: **https://guilhermenascimento-bit.github.io/Portfolio/**

Static frontend (plain HTML, CSS and JavaScript, no build step) hosted on GitHub Pages. Dark and light themes, English and Portuguese. The "Live" section consumes my own backend, [portfolio-api](https://github.com/GuilhermeNascimento-bit/portfolio-api) (FastAPI + Redis), which serves my GitHub data and request metrics.
